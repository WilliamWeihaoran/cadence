Common Checks

  • If Calendar features do not work, confirm that Cadence has Calendar access in macOS System Settings.
  • If AI features do not work, confirm that an OpenAI API key is saved in Cadence Settings and that your network connection is available.
  • If sync appears delayed, confirm that iCloud is available and that you are signed in to iCloud on the device.
  • To delete your Cadence account and data, open Settings, Account and choose Delete Account, or open Settings, Data Safety.
  • If a migration or restore fails, open Settings, Data Safety and check available local backups.

Privacy

Read the Cadence Privacy Policy for information about app data, Calendar access, iCloud sync, AI features, and deletion controls.
